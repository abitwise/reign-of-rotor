  <action>
Create the `apps/game/src/render/visuals/` directory with two manager classes.

**EnemyVisualManager** (`enemyVisualManager.ts`):
- Class that takes `Scene` in constructor
- Creates a shared `StandardMaterial` with olive-drab military color: diffuseColor(0.28, 0.32, 0.26), specularColor(0.08, 0.08, 0.06), emissiveColor(0.02, 0.02, 0.02)
- Maintains `Map<Entity, AbstractMesh>` for active enemy meshes
- `update(enemies: EnemyState, getTransform: TransformProvider)` method:
  - For each entity in `enemies.killedUnits`, dispose and delete the mesh
  - For each unit in `enemies.units`, if no mesh exists create one via `createEnemyMesh(unit.type)`, then update mesh position from `getTransform(unit.entity)`
- `createEnemyMesh(type: EnemyUnitType)` builds distinct silhouettes using `Mesh.MergeMeshes`:
  - `'sam'`: Low cylinder base (diam 3.2, h 0.8) + box turret (1.4x1.2x1.8) + two angled cylinder launcher tubes (diam 0.35, h 2.0, rotX -0.5)
  - `'radar'`: Cylinder tower (diam 0.6, h 3.5) + disc at top (radius 1.8, tilted) + flat cylinder base (diam 2.0, h 0.4)
  - `'vehicle'`: Elongated box body (2.4x1.4x4.2) + smaller box cabin on top-front (2.0x0.8x1.6)
- All merged meshes get the shared military material, `isPickable = false`
- Do NOT call `freezeWorldMatrix()` since positions update each frame
- `dispose()` method cleans up all meshes and material

**MissileVisualManager** (`missileVisualManager.ts`):
- Class that takes `Scene` in constructor
- Maintains `Map<Entity, { mesh: Mesh, particles: ParticleSystem }>` for active missiles
- Creates emissive material for missile body: bright orange-white emissive (1, 0.85, 0.5), `disableLighting = true`
- `update(playerMissiles: MissileInstance[], samMissiles: SamMissile[], playerMissileMap: Map<Entity, MissileInstance>, samMissileMap: Map<Entity, SamMissile>, getTransform: TransformProvider)`:
  - Combine both missile arrays into a single iteration
  - For each missile entity, if no visual exists: create cylinder mesh (diameter 0.25, height 1.5, tessellation 6), apply emissive material, create ParticleSystem (capacity ~80) as smoke/fire trail emitter attached to the mesh. Use `createPointEmitter(Vector3(0,0,-0.5), Vector3(0,0,-1))`. Colors: color1(1, 0.8, 0.3, 1), color2(0.6, 0.6, 0.6, 0.8), colorDead(0.3, 0.3, 0.3, 0). Emit rate 60, lifetime 0.3-0.8, size 0.3-0.8, gravity(0, -1, 0), blendMode ADD. Start the particle system.
  - Update mesh position and rotation from transform
  - For missiles no longer in either map, stop particle system (`disposeOnStop = true`), dispose mesh, remove from tracking map
- `dispose()` method cleans up all tracked meshes and particle systems

Use `import type` for type-only imports. Follow project naming conventions. Use `@/` path aliases for internal imports.

**WeaponVfxManager** (`weaponVfxManager.ts`):
- Class that takes `Scene` in constructor
- `processCannonImpacts(impactEvents: CannonImpactEvent[], gunOrigin: Vector3)`:
  - For each impact event, create a `MeshBuilder.CreateLines` tracer from `gunOrigin` to impact position. Color bright yellow-orange (1, 0.9, 0.3), alpha 0.9. Register an `onBeforeRenderObservable` callback that disposes the line after 2 frames (use a frame counter, not setTimeout).
- `processExplosions(events: Array<{ position: { x: number; y: number; z: number }; radius: number }>)`:
  - For each event, create a sphere mesh (diameter = radius * 0.6, segments 8), position at event location. Apply StandardMaterial with emissiveColor(1, 0.85, 0.4), `disableLighting = true`, alpha 0.9. Register `onBeforeRenderObservable` callback: over 10 frames, expand scaling (1 + t*2) and fade alpha (0.9 - t). Dispose mesh and material after 10 frames.
- `dispose()` method (clean up any pending VFX -- track active flash meshes in a Set and dispose all)

**HudMarkerManager** (`hudMarkerManager.ts`):
- Class that takes container `HTMLElement` and `maxMarkers` (default 32) in constructor
- Creates a pool of `maxMarkers` absolutely-positioned div elements with class `enemy-marker`. Style: `display: none; position: absolute; will-change: transform; pointer-events: none`. Each div contains a diamond shape using CSS (a small rotated square, ~8x8px, border 2px solid #ff4444, background transparent, transform rotate(45deg)).
- `update(enemies: EnemyUnit[], camera: Camera, engine: Engine)`:
  - For each enemy unit, project world position (offset y+2 above unit) to screen space using `Vector3.Project()` with camera view/projection matrices and viewport dimensions
  - If screenPos.z is between 0 and 1 (in front of camera) AND within viewport bounds, show the marker div at that screen position using CSS transform translate. Otherwise hide it.
  - Hide unused markers (set display: none)
- `dispose()` removes all marker divs from container

**Wiring into createApp.ts**:
- In the `.then(async ([physicsContext, renderContext]) => { ... })` block in `createApp.ts`, after `bootstrapGameplay` returns:
  1. Import and instantiate all four visual managers: `EnemyVisualManager(renderContext.scene)`, `MissileVisualManager(renderContext.scene)`, `WeaponVfxManager(renderContext.scene)`, `HudMarkerManager(layout.uiHost, 32)`
  2. Add a new `scene.onBeforeRenderObservable.add(() => { ... })` callback (AFTER the existing one in bootstrap.ts, or alongside it). In this callback:
     - Call `enemyVisuals.update(gameplayContext.enemies, transformProvider)`
     - Call `missileVisuals.update(gameplayContext.missiles.missiles, gameplayContext.enemies.samMissiles, gameplayContext.missiles.missileMap, gameplayContext.enemies.samMissileMap, transformProvider)`
     - For cannon tracers: compute gun origin from player transform (get helicopter position, offset forward and down by rotating a local offset vector by helicopter quaternion). Call `weaponVfx.processCannonImpacts(gameplayContext.cannon.impactEvents, gunOrigin)`
     - Collect all explosion events: `[...gameplayContext.enemies.explosionEvents, ...gameplayContext.missiles.explosionEvents]`. Call `weaponVfx.processExplosions(allExplosions)`
     - Call `hudMarkers.update(gameplayContext.enemies.units, renderContext.camera, renderContext.engine)`
  3. Add visual manager disposal to the app's `destroy()` handler

The `renderContext.scene.onBeforeRenderObservable.add()` registration should happen in `createApp.ts` after gameplay is bootstrapped, NOT inside `bootstrap.ts`. This keeps bootstrap.ts clean and gives access to gameplay state.

For the HUD marker container, use `layout.uiHost` which is the existing UI overlay div. Add the enemy-marker CSS styles either inline on element creation or via a style block appended to the document head from `hudMarkerManager.ts`.

Important: The `TransformProvider` type is `(entity: Entity) => Transform | null` from `meshBindingSystem.ts`. Pass `(entity) => physicsContext.getEntityTransform(entity)` as the transform provider to visual managers.
